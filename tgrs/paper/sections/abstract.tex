We present ChebDepth, a monocular depth estimation pipeline that represents an image as a region-adjacency-style graph of superpixel centers and processes it with Chebyshev spectral graph convolutions.
Node features are projected back to a dense grid by barycentric interpolation over a Delaunay triangulation and decoded by a lightweight convolutional head.
The network is trained with a combination of mean-squared error, gradient matching, edge-aware smoothness, and a Dirichlet-energy graph regularizer.
